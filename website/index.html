The Crate Ecosystem

Modular Rust architecture built from the ground up for high-concurrency AI agent workflows.

crates/cinder-gui

GPU-accelerated eframe/egui interface with split panels, markdown rendering, chat threads, and live process inspection.

crates/harness-core

Core orchestration engine managing autonomous agent loops, tool dispatching, and safety guardrails.

crates/harness-models

Local GGUF model loader, prompt template management, and context window optimization routines.

crates/harness-tools

Secure sandboxed system tools for file editing, bash execution, regex searching, and test verification.

crates/harness-net

Async HTTP server and client adapters enabling headless API mode and external provider integrations.

crates/harness-store

High-performance local key-value store and knowledge graph state manager.
